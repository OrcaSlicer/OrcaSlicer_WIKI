# Releases

Release notes for each version of OrcaSlicer, newest first. Select a version to read the full changelog.

## Stable

- **[V2.4.2](release_2_4_2.md)** — Maintenance update focused on more dependable profiles, cloud sync, and printer connectivity, plus several crash fixes.
- **[V2.4.1](release_2_4_1.md)** — Maintenance update with a broad round of profile and preset fixes, a native Windows ARM64 build, and a reworked skirt and brim generator.
- **[V2.4.0](release_2_4_0.md)** — Bug fixes, a smoother Orca Cloud experience, and the ability to send sliced jobs to the printer as a packaged 3MF.

## Pre-releases

- **[V2.4.0 Beta](release_2_4_0_beta.md)** — Stability, speed, and print-quality work — greatly improved bridging and a new realistic rendering option.
- **[V2.4.0 Alpha](release_2_4_0_alpha.md)** — Introduces Orca Cloud (profile sync and sharing), Z Anti-Aliasing contouring, an Expert user mode, and native Wayland support for Linux.
