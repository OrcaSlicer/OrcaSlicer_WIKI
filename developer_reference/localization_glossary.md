# Translation Glossary

Cross-language reference of key OrcaSlicer terms, to keep translations
**consistent** within each language. The base column is English (the `msgid`).

This is a companion to the [Localization and translation guide](localization_guide):  
before translating a recurring term, check here for the established form so the same English word is always rendered the same way within a language.

## Kept in English (do not translate)

These are written verbatim in the `msgstr` in essentially all languages.  
Languages with non-Latin scripts (ja, ko, zh, ru, uk, th) keep the Latin acronyms/brand names but may add a translated descriptor. For entries that are ordinary words they follow their own regional standards instead, writing the term in the local script — transliterated (ja ホットエンド, uk *Хотенд*, ru *Хотэнд*) or as a native equivalent (zh_CN 热端); see the [translation table](#translation-table-glossary) for the form in use.

| Term | What it is, and why it stays in English |
| --- | --- |
| **OrcaSlicer** / Orca Slicer | The application's own name. Product and brand names are proper nouns and are never translated. |
| **Bambu Lab** / Bambu | Printer manufacturer brand. Proper noun. |
| **Orca Cloud** / OrcaCloud, **Bambu Cloud** | Names of the cloud sync/print services. Product names, kept as-is so they match the UI and account pages. |
| **Micro-Lidar** | Bambu Lab's branded calibration sensor. Trademark / product name. |
| **WebView2 Runtime** | Microsoft's embedded-browser component. Official product name — translating it would stop users from finding and installing it. |
| **AMS** | *Automatic Material System* — Bambu Lab's automatic filament changer. Established product acronym used worldwide. |
| **G-code** / G-Code / gcode | The machine-control language sent to the printer. Universal, industry-standard name; keep the hyphenated *G-code* spelling and never translate the bare `gcode` token used in filenames/settings. |
| **FDM** | *Fused Deposition Modeling* - the filament printing process. Standard technology acronym. |
| **SLA** | *Stereolithography* — the resin printing process. Standard technology acronym. |
| **HRC** | Rockwell C hardness scale, used for nozzle hardness. International measurement unit. |
| **LAN**, **IP**, **FTP**, **HTTPS** | Networking acronyms (local network, Internet Protocol, file transfer, secure HTTP). Universal technical acronyms. |
| **RAID** | *Redundant Array of Independent Disks* — a storage configuration. Standard acronym. |
| **SD** | *Secure Digital* memory-card standard. The acronym stays; the surrounding word may be translated (e.g. *tarjeta SD*). |
| **UTF-8** / UTF8 | Unicode text-encoding standard. Standard name. |
| **I3**, **CoreXY**, **H-bot**, **Delta** | Printer motion-system / frame types (I3 is Prusa i3 style; CoreXY and H-bot are belt arrangements; Delta is the parallel-arm type). Established machine-design names. |
| **IDEX**, **IQEX** | *Independent Dual Extruder* / *Independent Quad Extruder* — printers with two or four independently moving carriages, which OrcaSlicer drives in parallel printing. Established hardware acronyms, written together as *IDEX/IQEX* in the UI. |
| **Arachne** | Name of variable-width wall-generation engine. Proper name of the algorithm. |
| **Pressure Advance**, **Linear Advance** | Firmware feature that compensates for extrusion-pressure lag (*Linear Advance* is Marlin's name for it). Established firmware term shared across slicers and firmware — kept in English so it matches firmware settings and documentation. In *"Adaptive Pressure Advance"*, only the *"Pressure Advance"* part stays in English; the qualifier *"Adaptive"* is translatable (e.g. es: *"Pressure Advance adaptativo"*). |
| **Bowden** | Extruder drive type, named after the Bowden cable. Proper noun / established term. |
| **Hotend** | The heated end of the extrusion system — heat sink, heat break, heater block, heater cartridge and thermistor — that melts the filament, with the **nozzle** screwed into it. Established hardware term shared across slicers, firmware and printer documentation. |
| **File formats**: 3MF, STL, STEP, OBJ, AMF, ZIP | File-format names and extensions. Extensions are fixed identifiers, not words, so they are never translated. |
| **Materials**: PLA, PETG, PET, PCTG, ABS, ASA, PC, PC-ABS, PC-PBT, PA, PA6, PA11, PA12, PAHT, PE, PP, PPA, HIPS, TPU, TPI, PVA, PVB, PVDF, BVOH, CoPE, EVA, FLEX, SBS, POM, PHA, PI, PCL, PEI, PEEK, PEKK, PES, PPS, PPSU, PSU — plus `-CF` (carbon-fiber), `-GF` (glass-fiber) and `-AERO` (foaming) variants | Polymer/material abbreviations from the material database (PEI is also the plate surface). Standard chemical/industry abbreviations, never translated — including the `-CF` / `-GF` / `-AERO` suffixes and blend names like PC-ABS. |
| **CF**, **GF** (also the `-CF` / `-GF` suffixes) | *Carbon Fiber* and *Glass Fiber* reinforcement blended into a base polymer (e.g. PLA-CF, PA-GF). Kept as the English abbreviation so it matches the material name. |
| **G-code commands**: `M141`, `M191` | Literal printer commands (set / wait for chamber temperature). They are machine instructions and must be copied exactly. |
| **Macros & variables**: `PRINT_START`, `CHAMBER_TEMP`, `CHAMBER_MIN_TEMP`, `chamber_temperature`, `chamber_minimal_temperature` | Literal identifiers used in custom G-code. Translating or altering them breaks the macro/variable reference. |
| **Inch symbol**: `″` (U+2033) | The abbreviation for inches (`msgctxt "inches"`, `msgid "in"`). Use the Unicode double-prime character `″` (U+2033) as the standard — not a straight quote `"`, two apostrophes `''`, or the letters *in*. It is a script-neutral typographic symbol, so it stays the same in every language. |

### Updating the glossary

The [translation table](#translation-table-glossary) is **generated**.  
Its source is the per-language files in `developer_reference/glossary/`, so a translator opens only the file for their language. Edits made directly to the table in this page are overwritten the next time the generator runs.

The files are **tab-separated**, so a cell is exactly the text between two tabs and commas or quotation marks inside a description need no escaping. They open as a spreadsheet in Excel, LibreOffice and Google Sheets — just keep the tabs when saving, and never type one inside a cell.

| File | Contents |
| --- | --- |
| `<lang>.tsv` (`de.tsv`, `fr.tsv`, …) | One row per term, named after the language's folder under `localization/i18n/`. Columns: `English` (the term, i.e. the `msgid` as it appears in the UI), `Description` (one sentence saying what the term is, so a translator can render it without opening the slicer) and the language's translation. Leave the translation empty when the catalog has no established one — the table shows `—`. |
| `terms.tsv` | The English term and its description. It defines which terms exist and their order. |
| `languages.txt` | The language codes, in the column order of the table. |

The `English` and `Description` columns of every `<lang>.tsv` repeat `terms.tsv`, so each file reads on its own. Change them in `terms.tsv` only and run `--sync` to copy them into the language files.

To correct or add a translation, edit your language's file and regenerate the page:

```bash
python generate_glossary.py --update   # rewrite the table in this page
```

To add a term, add a row to `terms.tsv`, run `python generate_glossary.py --sync`, fill the rows in the language files, then run `--update`. To add a language, list its code in `languages.txt`, run `--sync` and fill the new file.

Extra:

```bash
python generate_glossary.py              # print the table and report problems or a stale page
python generate_glossary.py --sync --prune   # also drop rows whose term was removed from terms.tsv
python generate_glossary.py --check      # exit 1 on an inconsistent file or a stale page
```

Every pull request that touches the glossary files or this page runs `--check` in CI (`validate_localization_glossary.yml`). It fails when a language file is missing a term or carries a different description, or when the table in this page does not match the files — run `--sync` and `--update` and commit the result.

## Language specifics

This is a place for translators to specify some unique caracteristics for their translations.

### Russian (ru)

- **Nozzle** — use *Сопло* (the nozzle tip). *Экструдер* is Bambu's legacy label for the whole toolhead; the two senses are being split by `msgctxt`, so do **not** use *Экструдер* for the nozzle tip.
- **Hotend** — *Хотэнд*, spelled with **э** (not *Хотенд*, which is the Ukrainian form).
- **Toolhead** — never *головка*, which is the 2D-printer word. Use *[печатающая] голова* / *каретка* for the moving assembly (*Парковка головы*, *параллельных печатающих голов*). Keep it distinct from the swappable module it carries: on tool/hotend-changers that module is the hotend (*насадка*), while *инструмент* belongs to `tool` / `tool change` strings. See [PR #14970](https://github.com/OrcaSlicer/OrcaSlicer/pull/14970) for the ongoing discussion.
- Several one-word UI strings are homonyms that need a different Russian form per context and now carry a `msgctxt`; translate each context separately:
    - **Cut** — *Разрезать* (cut tool) / *Вырезать* (clipboard, Ctrl+X)
    - **Left** / **Right** — *Слева* / *Справа* (camera direction) / *Левое* / *Правое сопло* (nozzle side)
    - **Smooth** — *Сгладить* (action) / *Плавный* (timelapse mode)
    - **Edit** — *Правка* (menu) / *Изменить* (verb)
    - **Assemble** — *Объединить в сборку* (action) / *Собрать* (assembly tool)
    - **End** — keep *End* (keyboard key) / *до конца* (layer range)

### Turkish (tr)

Settled in [PR #15119](https://github.com/OrcaSlicer/OrcaSlicer/pull/15119) and continued in [PR #15309](https://github.com/OrcaSlicer/OrcaSlicer/pull/15309), which finished the `Jerk` sweep, re-termed the object instance and standardised `Mirror`:

- **Jerk** — *Sarsıntı*, everywhere. The `Maximum jerk of the X/Y/Z/E axis` strings add the English word in parentheses (*maksimum sarsıntısı (Jerk)*), which is fine; `set_accel_and_jerk()` is a code token and stays verbatim.
- **Instance** — *Eş kopya* for the object sense (`Add instance`, `Set number of instances`, `Instance manipulation`, `Fill bed with instances`). Chosen over a bare *Kopya* so it cannot collide with the Clone/copies family: `Fill bed with instances` is *Yatağı eş kopyalarla doldur* and `Fill bed with copies` is *Yatağı kopyalarla doldur* — two different actions, two different words.
- **Instance (application)** — *Örnek*, never *Kopya* or *Eş kopya*. This is `Allow only one OrcaSlicer instance`, `Current Instance`, `Current Instance Path: `, `Failed to launch a new instance.` and the printer-host field, where the instance is a running program, not a placement on the plate.
- **Clone** — *Klon* (`Clone`, `Clone Selected`, `Clone Objects`). Now that the object instance takes *Eş kopya*, the clone family can keep *kopya* for its `copies` strings. Still outstanding: `Clone copies of selections` is *Seçimlerin kopyalarını kopyala* ("copy the copies") and needs the *klon* wording.
- **G-code** — kept in English, hyphenated, with Turkish case suffixes attached by apostrophe (*G-code'u dışa aktar*, *G-code'un*, *G-code'a*, *G-code'ları*); the compound suffix simply drops (*G kodu dosyaları* → *G-code dosyaları*). Swept in [PR #15309](https://github.com/OrcaSlicer/OrcaSlicer/pull/15309), which converted 108 entries spelling it as *kod* (14 variants: *G kodu*, *G-kodu*, *G-kod*, *G Kodu*, *G-Kod*, *G kod*, …) plus 28 more using a bare lowercase *gcode* in prose. What must never be converted: the `.gcode` / `.gcode.3mf` file extensions and the setting IDs that embed the token (`layer_change_gcode`, `before_layer_change_gcode`).
- **Mirror** — *Aynala*, the verb, including the short `Mirror` input label; not *Ayna* (the noun) and not *yansıt*, which reads as project/reflect.
- **Bed / Build plate** — *Yatak* for the bed, *Plaka* for the plate. *Tabla* is a third word still left in seven strings, and each belongs to one of the other two: `Bed adhesion`, `Excluded bed area` and the first-layer acceleration tooltip are *Yatak*; `Delete all objects on the current plate`, `Cannot send a print job for an empty plate.`, `max triangle count per plate for slicing` and `max slicing time per plate in seconds` are *Plaka*.
- Keep label and tooltip on the same term. Where a tooltip enumerates options — as the intra-layer order one does — quote each option exactly as its own msgid is translated (*Varsayılan*, *Nesne listesi olarak*, *Hepsinin en iyisi (en kısa yol)*, *Yılankavi*), so the text and the dropdown match.

### French (fr)

- **Prime tower / Wipe tower** — *Tour d’amorçage* for both English names (settled in [PR #396](https://github.com/OrcaSlicer/OrcaSlicer_WIKI/pull/396)), including `Wipe tower type`, `Wipe tower volume` and the wipe-tower cost strings. *Essuyage* is kept for the nozzle `Wipe` (`Wipe speed`, `Wipe distance`), and *Tour de purge du tapis* for the `Belt purge tower`.
- **Chamber** — *Caisson*, in the label and in `Chamber temperature`. *Chambre* is no longer used.
- **Gizmo** — *gizmo* in every gizmo string (`Entering Cut gizmo` → *Entrée dans le gizmo Couper*), not *outil*.
- **Color names** — the CSS and Orca palette names are translated (*Bleu ciel*, *Vert forêt*). The RAL names follow the official French RAL names, noun first (*Bleu vert*, *Rouge pourpre*).
