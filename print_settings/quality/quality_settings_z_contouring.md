# Z Contouring

Enable Z-layer contouring (aka Z-layer anti-aliasing).

## Minimize wall height angle

Reduce height of top surface perimeters to match height of model edge.
Effects perimeters whose slope is less than this angle in degrees.
Reasonable value is 35. Set 0 to disable.

## Minimum z height

Minimum z layer height. Also controls slicing plane.

## Don't alternate fill direction

Disable alternating fill direction when using Z contouring.
