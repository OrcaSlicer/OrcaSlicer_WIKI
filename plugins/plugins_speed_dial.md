# Actions Speed Dial

> [!IMPORTANT]
> NEW FEATURE: **Actions Speed Dial**  
> Available in: [Nightly builds](https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/nightly-builds) or Releases greater than **2.4.2**.

The Actions Speed Dial is a search-first launcher for enabled **Script** plugin capabilities.
It is available from the **Prepare** tab by pressing **Space**.

## Use the speed dial

1. Press **Space** while the Prepare tab is active.
2. Type in the search box to filter actions by action name or plugin name.
3. Press **Enter** or double-click an action to run it.
4. Press **Escape** to clear the search, then press it again to close the launcher.

The action list is ordered by recent and frequent use. Each action runs through the same Script
capability path as the Plugins dialog. The first run asks for confirmation; enable **Don't ask
again for this action** if confirmation is no longer needed.

## Favourites

Click the star beside an action to pin it to the favourites bar. Favourites retain their order and
persist across restarts. You can also:

- use the arrow keys to move between the favourites bar and the action list;
- right-click a favourite to move it left or right, or unpin it.

Only currently loaded actions appear in the favourites bar. If a plugin is unloaded or a capability
is disabled, its action is unavailable until it becomes active again.
